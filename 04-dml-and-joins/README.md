**Objective:** Study core data retrieval and modification queries such as `SELECT`, `UPDATE`, `DELETE`, `INSERT`, as well as using joins (`JOIN`) and aggregate functions with grouping (`GROUP BY`, `HAVING`) using SQL.

( Изучение основных запросов выборки и модификации данных, таких как SELECT, UPDATE, DELETE, INSERT, а также использование объединений (JOIN) и агрегатных функций с группировкой (GROUP BY, HAVING) с использованием языка запросов SQL.)

---

## 1. Key SQL Concepts Covered

- **Basic Retrieval & Filtering:** Using `SELECT`, `WHERE`, `BETWEEN`, and `ORDER BY` to extract specific data and sort it (e.g., searching for cars of a specific brand or filtering sales by dates).
- **Data Aggregation:** Applying functions like `COUNT`, `SUM`, `MAX` along with `GROUP BY` and `HAVING` to calculate and filter grouped metrics (e.g., calculating total revenue for each specific manager).
- **Table Joins (`JOIN`):** Restoring relationships between tables using `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN` to generate readable reports, replacing numeric foreign keys (`ID`) with actual manager surnames and car brands.
- **Data Modification (DML):** Adding new records to master data tables (`INSERT INTO`), selectively updating existing data (`UPDATE ... SET ... WHERE`), and safely deleting journal rows (`DELETE FROM ... WHERE`) with strict control over filtering conditions.

(Базовая выборка и фильтрация: Использование SELECT, WHERE, BETWEEN и ORDER BY для извлечения конкретных данных и их сортировки (например, поиск автомобилей определенной марки или фильтрация продаж по датам).
Агрегация данных: Применение функций COUNT, SUM, MAX вместе с GROUP BY и HAVING для вычисления и фильтрации сгруппированных метрик (например, подсчет суммарной выручки для каждого конкретного менеджера).
Соединение таблиц (JOIN): Восстановление связей между таблицами с помощью INNER JOIN, LEFT JOIN и RIGHT JOIN для получения удобочитаемых отчетов, заменяющих числовые внешние ключи (ID) на реальные фамилии менеджеров и марки автомобилей.
Модификация данных (DML): Добавление новых записей в справочники (INSERT INTO), точечное обновление существующих данных (UPDATE ... SET ... WHERE) и безопасное удаление строк журнала (DELETE FROM ... WHERE) со строгим контролем условий фильтрации.)
